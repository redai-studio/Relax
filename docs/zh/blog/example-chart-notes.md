## 先交代单位

同样的数字，在不同单位下表达的含义可能完全不同。标明单位和范围，是让图表可以独立阅读的第一步。

## 用表格说明一个例子

以下仅为虚构的展示数据。

| 观察点 | 示例值 / 秒 |
| --- | ---: |
| 第一次 | 4.2 |
| 第二次 | 4.0 |
| 第三次 | 4.3 |

## 把描述和解释分开

“三次记录接近”描述了表中的现象；“原因是什么”则需要额外证据。图表注释可以先写清楚观察，再列出需要进一步验证的解释。
