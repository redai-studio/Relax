## 从最小记录开始

复现说明可以先回答三个问题：使用了什么输入，在哪个环境运行，以及结果保存在哪里。信息不必很多，但要能对应到同一次实验。

## 把步骤写成顺序

1. 准备固定的示例输入。
2. 记录本次运行的条件。
3. 保存输出及观察结果。
4. 在相同条件下重复一次。

## 保留差异

如果第二次运行与第一次不同，先记录差异。把变化留在笔记里，往往比只保留一个汇总值更有帮助。
