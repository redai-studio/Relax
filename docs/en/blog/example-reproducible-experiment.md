## Start with a small record

A reproduction note can begin with three questions: which inputs were used, where the experiment ran, and where the outputs were saved. Keep the information tied to the same run.

## Put the steps in order

1. Prepare fixed example inputs.
2. Record the conditions of the run.
3. Save the outputs and observations.
4. Repeat under the same conditions.

## Keep the differences

If the second run differs from the first, record the difference. Keeping that variation in the note is often more useful than retaining only one aggregate value.
