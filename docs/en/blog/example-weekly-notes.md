## Write down the questions first

This fictional weekly note helps preview a list of ten articles.

1. Which experimental conditions should be fixed in the record?
2. Which recurring questions deserve an article?
3. Which conclusions still need an independent check?

## Give each question a next step

A question does not need an immediate answer. Record the missing evidence and the scope of the next check so the discussion has somewhere to continue.

## Leave room for discussion

> Sharing a question without an answer can still be useful.

A short note can become a longer article, or it can stay short. What matters is helping readers understand what was observed.
