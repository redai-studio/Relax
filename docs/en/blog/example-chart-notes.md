## State the units first

The same number can mean something entirely different under another unit. Specifying units and scope is the first step toward a chart that can be read on its own.

## Explain with a table

These values are fictional display data.

| Observation | Example value / seconds |
| --- | ---: |
| First | 4.2 |
| Second | 4.0 |
| Third | 4.3 |

## Separate description from explanation

“The three records are close” describes the table. Explaining why requires additional evidence. A chart note can state the observation first, then list explanations that still need testing.
