# No.17 — 冻结条件特征缓存实验

复用冻结条件后，SenseNova 的稳态训练吞吐中位数提高 **7.7778%**，Qwen-Image-Edit 提高 **14.5436%**。低复用 SenseNova 负载下降 **20.6834%**，因此更适合条件会重复、且工作集能放入内存的训练任务。

## 结果

每对保持相同模型、初始 LoRA/优化器状态、seed、样本顺序和精度。收益公式为 `online_seconds / cached_seconds - 1`，表示吞吐提升，不是延迟下降比例。三对结果全部保留。

| 负载 | 第 1 对 | 第 2 对 | 第 3 对 | 中位数 |
|---|---:|---:|---:|---:|
| SenseNova，128 对重复样本 | +9.2914% | +5.4866% | +7.7778% | **+7.7778%** |
| Qwen-Image-Edit，128 对重复样本 | +14.4331% | +15.2332% | +14.5436% | **+14.5436%** |
| SenseNova，640 个不同样本 | −20.6834% | −19.3819% | −22.3100% | **−20.6834%** |

18 段都先从冷缓存运行 16 次预热更新，再测量 64 次更新。B8 使每段共消费 640 次样本；重复负载将 128 对真实编辑样本遍历五次，低复用负载从 1,024 行数据中消费 640 个不同样本。每个负载的实际顺序均为 AB / BA / AB，A 为在线编码，B 为缓存。

两种重复负载均从空缓存开始，编码 128 个条件后产生 512 次命中，无淘汰。SenseNova 留存约 17.994 GiB，Qwen 约 0.692 GiB。低复用负载没有命中，写入 640 次、淘汰 201 条，结束时占用 63.955 GiB，未超出每进程 64 GiB 预算。

## 测量条件

计时覆盖真实 `FSDPSFTTrainer` 更新中的图片准备等待、前向、反向、梯度归约/裁剪、Adam 和 scheduler。模型初始化另行统计，Ray/TQ 编排及 checkpoint I/O 位于稳态区间之外。

运行使用每张 143,771 MiB 的 H200、Torch 2.9.0+cu128、SDPA、确定性算法、BF16 计算、FP32 master/归约、LoRA rank/alpha 32、学习率 1e-4 和 seed 20261030。SenseNova 和 Qwen 分别使用 GPU2、GPU3 上独立的 world1 进程，CPU affinity 为 40–59、60–79。两条任务并发，共享 NUMA0 主机带宽。Qwen 第 3 对的 A 进程约 81.95% 时间与 SenseNova 重叠，B 则在对方结束后运行；前两对几乎全程并发，收益相近。

新增复现 runner 默认单卡串行执行全部 28 个阶段；上述实测运行使用两个并发的 world1 任务。

## 冷启动成本与资源

从冷缓存开始累计训练时间，三对 SenseNova 分别从第 24/28/57 次更新起持续回本，Qwen 为 18/1/13。六条高复用缓存路径在 80 次更新结束时均更快；比较含初始化的训练报告或整个子进程回执也仍然为正。低复用三对均未在此窗口内持续回本。

| 资源 | SenseNova 重复 A / B | Qwen 重复 A / B | SenseNova 低复用 A / B |
|---|---|---|---|
| 峰值 GPU allocation | 约 38.50 / 38.50 GiB | 约 64.35 / 64.35 GiB | 约 38.50 / 38.50 GiB |
| 最大采样进程 RSS | 2.64 / 20.76 GiB | 2.78 / 3.55 GiB | 2.65 / 68.75 GiB |
| 结束时缓存驻留 | 0 / 17.994 GiB | 0 / 0.692 GiB | 0 / 63.955 GiB |

RSS 在更新中采样，模型加载高水位另有记录，存储样本记录阶段边界的运行文件大小及全局文件系统/SHM 可用量。

## 数值证据与复现

数值报告从同一初始状态比较在线 A1/A2、缓存 cold/warm。两个模型的 loss、逐参数梯度和 FP32 更新量均报告 bitwise exact，RNG 状态一致，缓存张量内容也精确一致。对照覆盖 seed 20261030、B8 下八个真实样本的一次更新。

公开证据位于 `examples/frozen_condition_cache/results/h200-20261103/`，保留数值比较报告和 18 段逐步性能记录。公开副本对机器路径及标识脱敏，原文件哈希见证据 manifest。文件索引见该目录 README 和 `summary.json`。

审查包未包含原始 trajectory、初始状态张量及大 DCP 文件。可下载的完整张量证据地址仍待补充，单凭 JSON 报告不能重新计算这些张量对照。

复现步骤见[冻结条件特征缓存](../zh/guide/frozen-condition-cache.md)及 `examples/frozen_condition_cache/` 的 README，模型/数据版本和文件哈希在实例中固定。
